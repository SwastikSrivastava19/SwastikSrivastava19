## ◈ Featured Projects

<details>
<summary><strong>⬡ ContextBridge — AI Context Preservation Chrome Extension</strong></summary>

<br/>

A production Chrome extension engineered to eliminate context loss when switching between AI platforms. ContextBridge captures, serializes, and injects conversation state across ChatGPT, Claude, Gemini, Copilot, and Grok — preserving the full reasoning thread without copy-paste friction. Ships with a Prompt Enhancer powered by Groq's `llama-3.3-70b-versatile` model for real-time prompt optimization.

| Attribute | Detail |
|-----------|--------|
| **Stack** | JavaScript, Chrome Extension API, Groq API (LLaMA 3.3 70B) |
| **Scale** | Multi-platform: ChatGPT, Claude, Gemini, Copilot, Grok |
| **Performance** | Sub-100ms context injection via DOM-level state serialization |
| **Distribution** | GitHub Releases (Chrome Web Store registration in progress) |
| **Impact** | Eliminates context re-entry overhead for power AI users |
| **Repository** | [github.com/SwastikSrivastava19/ContextBridge](https://github.com/SwastikSrivastava19/ContextBridge) |

The architecture decouples context extraction from injection, making it trivially extensible to new AI platforms. Each platform adapter implements a shared interface, and the Prompt Enhancer runs as an independent module with its own API boundary — so LLM dependencies don't leak into the core extension logic.

</details>

<details>

A performance-first developer portfolio deployed on Cloudflare's edge network. Built with TanStack Start (file-based routing, SSR), React, and Supabase for dynamic content and admin-controlled project listings. | Attribute | Detail |
|-----------|--------|
| **Stack** | TanStack Start, React, Supabase, Cloudflare Workers |
| **Scale** | Global CDN edge deployment (150+ PoPs) |
| **Performance** | ~0ms cold start, edge-cached static + dynamic content |
| **Security** | Admin RBAC via Supabase Row-Level Security policies |
| **Impact** | Production portfolio with measurable Lighthouse scores |
| **Repository** | [swastik-s-tech-hub.yashusrivastava4145.workers.dev](https://swastik-s-tech-hub.yashusrivastava4145.workers.dev) |

Architected with environment-specific configuration via Wrangler secrets, resolving deployment pipeline issues across Vercel/Netlify/Railway before settling on Cloudflare Workers as the only runtime that handles TanStack's SSR requirements cleanly at zero infrastructure cost.

</details>

<details>
<summary><strong>⬡ Real-Time Chat Application — WebSocket Architecture</strong></summary>

<br/>

A low-latency messaging system built on persistent WebSocket connections, engineered for real-time bidirectional communication with production-quality UX: typing indicators, presence detection, message timestamps, and connection recovery.

| Attribute | Detail |
|-----------|--------|
| **Stack** | React, Node.js, WebSockets (ws), JavaScript |
| **Scale** | Multi-client concurrent connections |
| **Performance** | Sub-50ms message propagation over local network |
| **Security** | Session-based user identification |
| **Impact** | Demonstrates full-duplex network programming at the application layer |
| **Repository** | [github.com/SwastikSrivastava19](https://github.com/SwastikSrivastava19) |

The state management layer is designed to minimize React re-renders — only message list and presence map updates trigger component reconciliation. Async event handling is centralized in a single WebSocket manager, keeping component logic clean and testable.

</details>
